用 Junie CLI 对接 ZenMux：终端 AI 编程代理的统一模型入口实践

在 AI 编程工具越来越碎片化的今天，开发者常常需要在多个模型和多个平台之间切换。JetBrains 的 Junie CLI 作为一款真正的 agentic coding 工具，已经能在终端里独立完成代码审查、重构、测试修复等复杂任务；而 ZenMux 作为带保险赔付机制的企业级大模型聚合平台，提供了统一的 OpenAI / Anthropic 兼容接口和智能路由。把两者对接起来，就能用一个终端命令，调用全球上百个顶尖模型，同时享受计费透明与质量兜底。

下面分享完整的对接方法与实践建议。

为什么选择 Junie CLI + ZenMux

Junie CLI 的核心优势在于：

  • 真正的 agent 循环：它会自己规划、执行、验证，而不是单纯聊天。
  • LLM-agnostic：不锁定单一厂商。
  • 支持 BYOK 与自定义模型，可直接对接任何 OpenAI 兼容端点。
  • 可在终端、JetBrains IDE、CI/CD 中统一使用。

ZenMux 的核心价值则是：

  • 一个 API Key 调用 OpenAI、Anthropic、Google、DeepSeek、Qwen、Kimi 等 100+ 模型。
  • 智能路由与故障转移。
  • 独特的 AI 保险机制：效果不佳、延迟过高时自动赔付。
  • 完整兼容 OpenAI Chat Completions 协议。

两者结合后，Junie 负责“会干活”，ZenMux 负责“用最好的模型干活，并兜底质量”。

一、安装 Junie CLI

macOS / Linux：

curl -fsSL https://junie.jetbrains.com/install.sh | bash

Windows（PowerShell）：

powershell -NoProfile -ExecutionPolicy Bypass -Command "iex (irm 'https://junie.jetbrains.com/install.ps1')"

也可以用 Homebrew 或 npm：

brew tap jetbrains-junie/junie && brew install junie
# 或
npm install -g @jetbrains/junie

安装后验证：

junie --version

二、获取 ZenMux API Key

  1. 打开 zenmux.ai 注册/登录。
  2. 根据场景选择套餐：
    • Pay As You Go：按量付费，适合正式项目，无速率限制。
    • Builder Plan：固定月费（从 $20 起），适合个人开发与学习。
  3. 在控制台创建 API Key。
  4. 到 Models 页面 查看模型 slug（例如 anthropic/claude-sonnet-5.5、openai/gpt-5.5、google/gemini-3.8-flash）。

ZenMux 的 OpenAI 兼容地址是：

https://zenmux.ai/api/v1

三、创建自定义模型配置（核心步骤）

Junie CLI 通过 JSON Profile 支持自定义端点。推荐放在用户目录：

mkdir -p ~/.junie/models

创建文件 ~/.junie/models/zenmux.json：

{
  "id": "anthropic/claude-sonnet-5.5",
  "baseUrl": "https://zenmux.ai/api/v1/chat/completions",
  "apiType": "OpenAICompletion",
  "apiKey": "${ZENMUX_API_KEY}",
  "displayName": "ZenMux Claude Sonnet",
  "providerName": "ZenMux",
  "primaryModel": {
    "id": "anthropic/claude-sonnet-5.5"
  },
  "fasterModel": {
    "id": "google/gemini-3.8-flash"
  }
}

关键字段说明：

  • id：ZenMux 上的模型 slug。
  • baseUrl：必须写完整路径 /chat/completions。
  • apiType：固定使用 OpenAICompletion。
  • apiKey：建议用环境变量，避免把密钥写进文件。
  • primaryModel / fasterModel：主模型和辅助模型可以分开配置，提升效率。

设置环境变量：

export ZENMUX_API_KEY="你的_ZenMux_API_Key"

项目级配置可放在仓库的 .junie/models/ 目录，方便团队共享（记得用环境变量保护密钥）。

四、启动与日常使用

进入项目根目录：

cd /home/iChochy/code/project
junie

在交互界面输入 /model，选择 custom:zenmux 即可。也可以直接指定：

junie --model custom:zenmux

常用命令速览：

功能 命令 / 操作
启动交互会话 junie
切换模型 /model
计划模式（只读分析） /plan 或 Shift+Tab
新开会话 /new
查看账户 /account
退出 /quit
无头模式（CI） junie --model custom:zenmux "任务描述"

五、实践建议与注意事项

  1. 模型选择很重要
    Junie 是真正的 agent，对模型的工具调用能力和长上下文保持要求较高。推荐优先使用 Claude Sonnet / Opus、GPT 系列、Gemini Pro 等强模型。过小或过度量化的模型容易出现指令漂移、工具调用失败或中途放弃任务。

  2. 计费完全透明
    使用自定义 Profile 后，所有请求都走 ZenMux，JetBrains 不再额外收费。你可以在 ZenMux 控制台实时查看 token 用量和费用。

  3. 安全与可维护性
    永远用 ${ZENMUX_API_KEY} 这种环境变量写法，避免密钥进入 Git。团队共享时，把 baseUrl 和模型配置放进仓库，密钥通过 CI 环境变量注入。

  4. 故障排查

    • 如果提示找不到模型，检查 slug 是否与 ZenMux Models 页面完全一致。
    • baseUrl 写错路径是最常见问题，务必带 /chat/completions。
    • 环境变量未生效时，Junie 会明确报错缺少变量名。

结语

把 Junie CLI 和 ZenMux 对接后，你获得的是一个「终端里的全能 AI 编程搭档 + 统一模型网关」。无论是个人日常开发，还是团队 CI 流水线里的自动化审查，都可以用同一套配置、同一个 API Key 完成。

官方文档：

  • Junie CLI 快速开始与自定义 LLM：https://junie.jetbrains.com/docs/custom-llm-models.html
  • ZenMux 快速开始：https://zenmux.ai/docs/guide/quickstart.html
