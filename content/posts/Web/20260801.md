做它的原因很简单：我想有一个**干净、本地、不用安装、也不用上传任何东西**的歌词工具。市面上很多歌词编辑器要么需要下载安装，要么要把音频传到服务器，我都不太喜欢。于是干脆自己写一个。

在线地址是：**https://lrc.ichochy.com**


### 它能做什么？

- 直接在浏览器里打开，导入本地音频（MP3、WAV、FLAC、M4A、OGG 等），马上就能看到波形图。
- 歌词以时间轴上的“块”的形式呈现，你可以直接**拖动**来微调时间戳，精度自动吸附到 0.01 秒。
- 双击就能改文字，点击空白处可以跳转播放位置。
- 播放时当前歌词会高亮，轨道会自动滚动跟随。
- 支持导入和导出标准 LRC 文件，元数据（标题、艺术家、专辑等）也可以一起编辑。
- 最重要的是：**所有数据都只在你本地处理**，不会上传到任何服务器。

界面我做成了近黑底 + 珊瑚橙的配色，会自动跟随系统深色/浅色主题，手机和电脑都能用。

### 技术上我怎么实现的

整个项目是纯静态的，没有后端、没有数据库。  
用了原生 HTML + CSS + JavaScript（ES Module），波形和播放控制用了 WaveSurfer.js（我把它本地内置了，不依赖 CDN）。音频参数是直接从文件头解析的，尽量保证采样率、码率这些信息准确。

代码已经开源放在 GitHub：  
https://github.com/iChochy/iLRC

### 怎么用？
1. 打开 https://lrc.ichochy.com  
2. 导入你的音频文件  
3. 导入已有 LRC，或者直接从空白开始做  
4. 边听边拖、边改  
5. 导出就行

不需要注册，不需要登录，打开就能用。
