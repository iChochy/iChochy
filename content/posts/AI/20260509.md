[ZenMux](https://zenmux.ai/invite/3KA0VI) 是一个 AI 模型聚合平台，可以轻松将 Claude Code 连接到更广泛的模型生态，包括Claude、 GPT、Gemini、Grok、Qwen 等众多强大模型，实现更灵活、更具性价比的开发体验。

Claude Code 是 Anthropic 推出的官方编码代理工具，它让开发者能够通过 CLI 高效地与 AI 协作完成代码编写任务。然而，默认情况下，它仅限于 Anthropic 的 Claude 系列模型

可以在线直连，高质量的 AI 模型聚合平台，推出了`订阅计划模式`和`按量付费模式`，支持多种付费模式包括 `支付宝`

## ZenMux + Claude Code 的优势

- **模型多样性**：除了 Claude 系列，还支持 GPT-5.2、Claude-4.5、Gemini-3、Grok 4.1、Doubao、Kimi、GLM-4.6、DeepSeek、Qwen3-Coder-Plus 等。
- **无缝集成**：无需修改 Claude Code 本身，仅通过环境变量切换服务端点。
- **灵活计费**：订阅计划适合个人开发，按量付费适合生产环境。
- **性能优化**：通过禁用实验性 Beta 功能，提升响应速度和稳定性。

## 安装 Claude Code

**重要**：npm/pnpm 安装方式已弃用，推荐使用原生安装。

### 卸载旧版本（如果适用）
```bash
npm uninstall -g @anthropic-ai/claude-code
# 或
pnpm uninstall -g @anthropic-ai/claude-code
```

### 推荐安装方式
```bash
# macOS/Linux 一键安装
curl -fsSL https://claude.ai/install.sh | bash

# Windows PowerShell
irm https://claude.ai/install.ps1 | iex
```

安装后运行 `claude doctor` 验证。

## 配置步骤

### Step 0: 获取 ZenMux API Key

- **订阅计划**（推荐个人使用）：sk-ss-v1-xxx，固定月费，性价比高。
- **按量付费**（生产环境）：sk-ai-v1-xxx，无限额，更稳定。


### Step 1: 配置 Shell 环境变量（推荐）

在 `~/.bashrc` 或 `~/.zshrc` 中添加：

```bash
export ANTHROPIC_BASE_URL="https://zenmux.ai/api/anthropic"
export ANTHROPIC_AUTH_TOKEN="sk-ss-v1-xxx"  # 替换为你的 Key
export ANTHROPIC_API_KEY=""  # 清除冲突

# 性能优化
export CLAUDE_CODE_DISABLE_EXPERIMENTAL_BETAS="1"
export CLAUDE_CODE_ATTRIBUTION_HEADER="0"
export CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC="1"
```

Windows PowerShell 用户类似配置 $PROFILE。

**为什么禁用 Beta 功能？**  
ZenMux 通过多个后端提供商路由请求，仅 Anthropic 原生支持所有 Beta 特性。禁用后可快速路由，提升速度。

### Step 2: 启动并使用

```bash
cd /home/iChochy/Code
claude
```

首次启动会自动通过 ZenMux 认证。

## 自定义默认模型

可通过环境变量映射 Haiku/Sonnet/Opus 层级到不同模型，例如：

```bash
export ANTHROPIC_DEFAULT_FAST_MODEL="anthropic/claude-haiku-4.5"
export ANTHROPIC_DEFAULT_BALANCED_MODEL="anthropic/claude-sonnet-4.5"
export ANTHROPIC_DEFAULT_POWERFUL_MODEL="anthropic/claude-opus-4.5"
```

## 最佳实践建议

1. **始终在新终端启动**，确保环境变量生效。
2. **项目级配置**：在项目目录使用 CLAUDE.md 定义规则和上下文。
3. **性能监控**：使用 `claude doctor` 检查状态。
4. **模型选择**：日常开发推荐 Sonnet 系列，复杂任务用 Opus。
5. **安全注意**：生产环境使用按量付费 Key，避免订阅 Key 滥用。
